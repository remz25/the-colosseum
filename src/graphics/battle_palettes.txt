# Per-character battle palettes (scripts/charpal.py): the original characters' battle sprites
# take their portraits' colours.
#
#   char ID  classes C,C,...  base default|ID     the classes this character can be (base class and
#                                                 promotions); base = whose FE8 palettes are recoloured
#                                                 (the old slot character's), or the class default
#   map RRGGBB RRGGBB ... -> RRGGBB               these colours (as they appear in the base palettes)
#                                                 take the target's hue/saturation, keeping their shading
#
# Print a base palette's colours with: py -3 scripts/charpal.py CHAR_ID CLASS_ID ...
